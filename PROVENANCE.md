# Provenance

This repository is original work by **Tran Trung Dung**, written from scratch on personal time and
personal hardware.

- No source code, configuration, schema, asset or data from any employer project is included. The
  techniques it demonstrates (a 30 Hz UDP relay, HMAC signed join tickets, ghost snapshots,
  client-side reconciliation, region bucketed matchmaking) are general practice; the code, the
  protocol and the numbers come from this repository, built and measured here.
- Third-party dependencies: none beyond the Go standard library.
- Every credential and secret in this repository is a local development placeholder.

If you believe something here belongs to you, please open an issue and it will be removed.
